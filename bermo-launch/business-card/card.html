Print Instructions
  1. Open this page in Chrome or Edge (not Safari — Safari scales print differently)
  2. Click the Print to PDF button above or press Ctrl/Cmd + P
  3. Set Paper size to Custom: 3.75in x 2.25in
  4. Set Margins to None
  5. Set Scale to 100% (Actual size)
  6. Save as PDF. Send to printer or Moo / Canva Print

Front and back print on separate pages. The red dashed line is the bleed edge. The solid red line is the trim line. The cyan dashed line is the safe zone. All artwork and text must stay inside the safe zone.
